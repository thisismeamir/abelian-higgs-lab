## Abelian–Higgs model

\[
\mathcal L = -\frac14 F_{\mu\nu}F^{\mu\nu} + (D_\mu\phi)^*D^\mu\phi - V(\phi)
\]

\[
D_\mu = \partial_\mu - ieA_\mu
\]

\[
V(\phi)=\frac{\lambda}{4}(|\phi|^2-\eta^2)^2
\]

\[
\beta = \frac{\lambda}{e^2}.
\]
