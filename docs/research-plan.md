# Research Plan — Simulation Notebook Laboratory

## Objective

Develop computational intuition for Abelian–Higgs simulations and empirically determine the numerical and architectural choices that should inform Kosmic.

## Questions

- What dimensionless formulation should be used?
- How should scalar and gauge fields be represented?
- Which lattice discretizations are appropriate?
- Which time integrator is appropriate?
- How should gauge structure be represented and tested?
- What resolution is required to resolve Nielsen–Olesen strings?
- How do moving strings behave numerically?
- What happens in controlled string collisions?
- What is required to form and measure a small network?
- Which numerical errors dominate?
- Which implementation choices matter for performance?

## Month-end outcome

A reproducible notebook collection and a design report containing experimentally justified choices, unresolved questions, and a proposed architecture for Kosmic.
